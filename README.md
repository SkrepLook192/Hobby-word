# 1. 🌍 О проекте

**Hobby Worlds** — социально-игровое мобильное приложение, которое помогает людям начать заниматься тем, чем они давно хотели заниматься, найти единомышленников и постепенно развивать свои навыки.

Главная идея проекта — превратить развитие хобби из абстрактного желания в понятный игровой путь.

Пользователь выбирает интересующее его направление, получает небольшие задачи, выполняет их, фиксирует прогресс, общается с другими пользователями и постепенно развивает собственный виртуальный мир.

### Основная концепция

> **Хобби → маленькие действия → прогресс → мотивация → сообщество → результат**

Hobby Worlds объединяет элементы:

* социальной сети;
* системы целей и задач;
* геймификации;
* поиска единомышленников;
* ленты публикаций;
* общения;
* виртуального 3D-мира.

# 4. ❗ Проблема

Многие люди хотят начать заниматься новым хобби, однако желание не всегда превращается в регулярные действия.

Основные проблемы пользователя:

* отсутствие мотивации;
* непонимание, с чего начать;
* слишком большие и сложные первые шаги;
* отсутствие единомышленников;
* отсутствие системы контроля прогресса;
* быстрое прекращение занятий;
* отсутствие эмоциональной связи с процессом развития.

Обычного списка задач недостаточно.

Пользователю необходимо видеть собственный прогресс и получать дополнительную мотивацию для продолжения.
