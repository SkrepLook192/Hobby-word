## 01. Идея и аудитория

Многие люди хотят рисовать, заниматься музыкой, спортом или другим увлечением, но откладывают занятия. После первых попыток мотивация снижается, понятного плана нет, а поддерживающее окружение ещё не сформировалось.

**Основная аудитория Hobby Worlds — студенты и молодые люди от 16 до 30 лет**, которым нужна структура занятий и наглядное ощущение продвижения.

| Потребность пользователя | Ответ в концепции Hobby Worlds |
| :--- | :--- |
| Понять, с чего начать | Небольшие задания по выбранному хобби |
| Замечать результаты занятий | Визуальные изменения в личном мире |
| Получать поддержку | Друзья, сообщения и лента прогресса |
| Сохранять интерес к занятиям | Игровые достижения, уровни и поддержка AI-персонажа |

Пользователь выбирает увлечение, выполняет задание и фиксирует результат. Прогресс становится частью его личного мира, а публикации помогают делиться успехами с другими людьми.

*Эти механики описывают концепцию продукта. Проект находится на стадии прототипа, разработка мира и игровых возможностей продолжается.*

## 02. Название и слоган

### Hobby Worlds

**Hobby** обозначает увлечения, а **Worlds** — личные миры пользователей и разнообразие их интересов. Название связывает реальное занятие с его игровым отражением: по мере развития навыков пользователь видит изменения в своём мире.

### Explore. Meet. Grow.

| Часть слогана | Смысл | Связь с продуктом |
| :--- | :--- | :--- |
| **Explore.** | Открывай увлечения | Выбери хобби и начни с небольшого задания |
| **Meet.** | Знакомься с людьми | Делись прогрессом и общайся с друзьями |
| **Grow.** | Развивай навыки | Выполняй задания и развивай свой мир |

Слоган описывает путь пользователя и помогает объяснить идею приложения несколькими словами.

## 03. Уникальное торговое предложение

> Для людей 16-30 лет, которым сложно регулярно заниматься хобби, мы создаём мобильное приложение Hobby Worlds, которое помогает сохранять мотивацию, в отличие от обычных списков задач и соцсетей, потому что связывает хобби-задания с прогрессом в личном 3D-мире и поддержкой друзей.

УТП соответствует шаблону практического занятия:

| Элемент | Формулировка для Hobby Worlds |
| :--- | :--- |
| Для кого | Люди 16–30 лет, которым сложно заниматься хобби регулярно |
| Что создаём | Мобильное приложение Hobby Worlds |
| Какую проблему решаем | Потеря мотивации и отсутствие регулярности |
| С какими альтернативами сравниваем | Обычные списки задач и социальные сети |
| На чём строится преимущество | Связь заданий с личным 3D-миром и поддержкой друзей |

## 04. Позиционирование и характер бренда

Hobby Worlds позиционируется как приложение для развития увлечений через игровые задания и личный мир. Общение с друзьями поддерживает этот процесс и даёт возможность делиться результатами.

### Характер бренда

| Качество | Как проявляется |
| :--- | :--- |
| **Современный** | Простой интерфейс, лаконичная типографика, светлая и тёмная темы |
| **Спокойный** | Сдержанная палитра и уважение к темпу пользователя |
| **Дружелюбный** | Обращение на «ты», понятные подсказки и поддерживающий тон |

### Как говорит Hobby Worlds

Тон общения помогает сделать следующий небольшой шаг. Формулировки остаются конкретными и не давят на пользователя.

| Ситуация | Пример сообщения |
| :--- | :--- |
| Первое знакомство | «Выбери хобби, которое давно хотел попробовать» |
| Начало занятия | «Начни с небольшого задания» |
| Завершение задания | «Ещё один шаг в твоём хобби. Поделишься результатом?» |
| Возвращение после перерыва | «Продолжим в твоём темпе» |

*Сообщения выше — примеры голоса бренда для будущих экранов приложения.*

## 05. Визуальная айдентика

### Логотип

В основе логотипа — **Земля с узнаваемыми материками**. Она символизирует личный мир пользователя и разнообразие увлечений. Образ связан с идеей продукта: реальные усилия получают визуальное отражение в мире Hobby Worlds.

В материалах используются два варианта: отдельный знак для иконки и знак с названием для презентаций и баннеров. Логотип представляет собой выбранный командой эскиз, созданный с помощью генератора изображений.

### Фирменная палитра

| Цвет | HEX | Роль |
| :--- | :--- | :--- |
| **Чёрный** | `#101010` | Тёмные фоны и основной текст на светлом фоне |
| **Белый** | `#FFFFFF` | Светлые фоны и текст на тёмном фоне |
| **Тёмная охра** | `#A67C32` | Логотип, выделения и акценты |

Чёрный и белый задают основу двух тем оформления. Охра помогает выделить знак и ключевые элементы, сохраняя сдержанный характер бренда.

### Типографика

| Применение | Начертание | Насыщенность |
| :--- | :--- | :--- |
| Заголовки и название проекта | **Inter Medium** | 500 |
| Основной текст и подписи | Inter Regular | 400 |

В бренде используется одна шрифтовая семья с двумя начертаниями. Inter поддерживает кириллицу и латиницу, поэтому подходит для русского текста и английского названия проекта. [Официальная страница шрифта](https://rsms.me/inter/).

### Правила применения

- Сохранять пропорции логотипа и оставлять свободное пространство вокруг знака.
- Подбирать светлый или тёмный вариант под фон материала.
- Использовать фирменную палитру и единые начертания шрифта.
- Для маленькой иконки оставлять только знак, а название и слоган размещать в более крупных форматах.
- Проверять читаемость текста и узнаваемость знака в итоговом размере.

## 07. Бренд, логотип и товарный знак

| Понятие | Значение в работе |
| :--- | :--- |
| **Бренд** | Образ проекта: его ценность, характер, тон общения и ожидания пользователя |
| **Логотип** | Графический символ, по которому узнают проект |
| **Товарный знак** | Обозначение для индивидуализации товаров, которому предоставляется правовая охрана; для услуг применяется понятие знака обслуживания |

Для Hobby Worlds разработаны название и визуальный знак. **Сведения об их регистрации в исходных материалах не приведены.** В этой работе они представлены как элементы учебной концепции бренда.

Роспатент указывает, что в качестве товарных знаков могут регистрироваться словесные, изобразительные и другие обозначения, а также их комбинации. Для проекта название, изображение Земли и их сочетание можно рассматривать как варианты обозначения для дальнейшей проверки. [Разъяснение Роспатента](https://rospatent.gov.ru/ru/faq/kakie-oboznacheniya-mogut-byt-zaregistrirovany-v-kachestve-tovarnyh-znakov).
